Two feedback channels

A session is a graph; the LLM strolls it and executes nodes. Two kinds of feedback reach the LLM — the test-script return and the graph topology. Both are feedback, but they are different channels: one is a likelihood, the other a belief.

Channel A — test-script return: an observation sample

Executing node \(v\) yields one draw \[ y_t \sim P(y \mid v, \theta), \qquad \hat\mu_v^{(1)} = y_t, \quad \operatorname{Var}[\hat\mu_v^{(1)}] = \sigma_v^2, \] where \(\theta\) is the unknown task parameter. The draw carries irreducible aleatoric entropy \(H[y_t \mid v, \theta] \ge 0\): the same node re-run need not return the same answer. The information a single return can transfer is bounded by the channel capacity of one execution — it never accumulates.

Channel B — graph topology: accumulated memory

The topology is a deterministic function of history: \[ G_{t+1} = \Psi(G_t, a_t, y_t), \qquad H[G_{t+1} \mid G_t, a_t, y_t] = 0. \] Memory adds no noise. It records visit counts \(n_v(t)\), and compresses \(n_v\) draws into a consistent estimator \[ \hat\mu_v^{(n_v)} = \frac{1}{n_v}\sum_{i \le n_v} y_{v,i}, \qquad \operatorname{Var}[\hat\mu_v^{(n_v)}] = \frac{\sigma_v^2}{n_v} \to 0, \] with deviation decaying exponentially (Chernoff): \[ P\big(|\hat\mu_v - \mu_v| > \epsilon\big) \le 2 e^{-2 n_v \epsilon^2}. \]

Theorem — Bayes decomposition, and why topology alone steers exploration

Every belief update consumes both channels simultaneously: \[ P(\theta \mid \mathcal{H}_t) \;\propto\; \underbrace{P(y_t \mid v_t, \theta)}_{\text{return: likelihood}} \cdot \underbrace{P(\theta \mid G_t)}_{\text{topo: prior}}. \] A return updates only the likelihood of the node just executed; the topology carries the whole belief \(P(\theta \mid G_t)\) — a sufficient statistic of history, so the LLM context needs \(\mathcal O(1)\) pointers instead of the raw stream. The unexplored set \(U_t = \{v : n_v(t) = 0\}\) is exactly where expected information gain is maximal: \[ \mathrm{IG}(v) = H[\theta \mid G_t] - \mathbb{E}_{y \sim P(y|v,\theta)} H[\theta \mid G_t, y], \qquad \arg\max_v \mathrm{IG}(v) \subseteq U_t. \] A single return can only describe the node already executed; only the topology can say where to sample next.

Corollary — variance ratio: one return is a sample with variance \(\sigma_v^2\); the topology delivers \(\sigma_v^2/n_v\). The gap grows unboundedly with visits: the return is the innovation, the topology is the memory that turns innovations into knowledge.

Test-script return = observation channel (likelihood · noisy · instantaneous).
Graph topology = belief channel (prior · deterministic · persistent).
Evidence without belief is noise; belief without evidence never moves.

Why both are necessary

Learning = posterior entropy drop. One update's information gain:

\[ \mathrm{IG}(y_t) = H[\theta \mid G_t] - H[\theta \mid G_t, y_t] \;\ge\; 0 \]

Without returns: belief frozen, \(\mathrm{IG}=0\) — never learn. Without topology: every return is a fresh \(\sigma^2\) sample, and the context window forgets it — learn and forget. In grasp, returns are written into history, so the topology is their superset: \(\sigma_v^2 / n_v \to 0\) survives the window. The memory must be external, because the window forgets by construction.

Self-improvement through graph evolution

The topology is the agent's evolving brain, not a static config.

Every pitfall is persisted as a new node or edge; every reflection upgrades the principle chain; every fork explores a risky branch on a child and keeps the parent clean. The same agent walking the same graph gets measurably better over rounds — the graph itself is the improvement: append-only, versioned, and never rewritten from scratch.

Play the necessity

One maze, three feedback policies: returns only · topology only · both.

A returns only — no memory

Random walk, nothing recorded. Variance stays \(\sigma^2\) — steps explode, never converges.

steps: 0

B topology only — no returns

Trusts a flawed prior map; execution returns are discarded. \(\mathrm{IG}=0\) — stuck on the first wrong wall forever.

steps: 0

C returns + topology

Same flawed prior, but each step's return corrects the map: \(\sigma^2/n \to 0\). Arrives.

steps: 0

Quick start

# LLM calls go through a curl subprocess to an OpenAI-compatible /chat/completions endpoint
# (OPENAI_API_KEY / OPENAI_BASE_URL / OPENAI_MODEL; key expanded by sh, never in argv)
$ make && ./grasp new graphs/meta.json --id my-meta
$ ./grasp walk my-meta --choose 1
$ ./grasp step my-meta m_act
$ ./grasp drive my-meta --max-steps 10
