Submit a topology to the market

  1. Author your topology as a versioned, append-only graph JSON (same schema as graphs/*.json — nodes, edges, entry, version).
  2. Fork Void-Universe-Club/grasp-site and add your file as market/<name>.json.
  3. Add an entry to market/index.json (id / name / version / author / tags / desc / file).
  4. Open a pull request — once merged, it appears here and is installable for everyone.

Contributions welcome. Fork github.com/Void-Universe-Club/grasp or the site repo grasp-site — new topologies for the market, docs, or core fixes.
