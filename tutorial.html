Command reference

Everything is a subcommand — scriptable from any agent loop.

CommandWhat it does
new <graph.json> [--id NAME]create a session from a graph file
walk <sid> [--choose N] [--auto N]stroll the topology — stitch descriptions into a sentence; multi-edge nodes ask; --auto N picks option N at every fork
step <sid> <node-id>execute one node (runs its cmd, records output)
insert <sid> <id> --desc "…" [--cmd "…"] [--edge from,to]persist knowledge — append a node (+edge), version++
add-edge <sid> <from> <to> [--label "…"]append an edge (topology evolution)
fork <sid>branch a child session (deep-copy graph + history)
merge <dst> <src>merge src's topology into dst — append-only union, conflicts keep dst
rebase <sid>sync the parent session's newest topology into this session
drive <sid> [--max-steps N]let the LLM decide actions (needs OPENAI_API_KEY)
status / list / show / dump-svginspect: session state · all sessions · one node · topology as SVG
